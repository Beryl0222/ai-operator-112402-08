# 手机端类目检索的双曲嵌入算子与子树扩写

这里的目录节点和坐标版本是用于设备联调的合成资料。使用 Node.js 22。运行 `npm ci --offline` 核对依赖锁，`npm run inspect` 查看资料字段，`npm test` 检查资料格式及相互引用。检视脚本只读取元数据。

## 数据格式

曲率固定为 −k，k>0，`lorentz` 时间坐标在首位、二次型为 −x0²+Σxi²，满足 −1/k。Poincaré 点半径严格小于 1/sqrt(k)，同曲率模型间解释等距。标签节点的覆盖球以自己的嵌入为心， radius 以双曲距离为单位，必须包含该节点内所有可达子节点的覆盖球。点更新是给定切向量的指数映射，输入有小误差时切向量应投影到该点的切空间，超过 tangentTol 拒绝。机器以 profile.relativeTol 判距离区间和近并列。向量交付消耗 readLimit，索引摘要只提供节点标识、边及当前半径上下界，读取计数单独。子树间没有隐式继承标签，只有 aliases 相同的引用可折叠。 证明用的半径是已有目录输入声明，必须对相关旋转族的已知变化重新检查，旧档的显式树可提供 conservative 数值。整棵树的预热索引阶段另有同一内存界，逐点取量额度只适用于上线查询。候选列表在 absTol 附近按不确定同组返回，页面可同时查看保留和排除原因。 nodes 的子节点为 9*id+1 至 9*id+9 内可用的编号。上线查询的 probe 是资料提供的该编号同坐标系向量，查询调用不需要取树外全量向量。

## 取数

`inputs/taxon-assets.json` 保存标定、规格和调用记录。记录中的范围除明确说明外从零开始，使用半开区间。批量数组按调用记录列出的顺序交付。taxonNode(id) 读标签结构和覆盖半径。taxonPoint(id,encoding) 返回指定坐标版本。
